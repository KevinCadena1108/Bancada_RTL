\section{Resultados detalhados}
\label{ap:resultados}

Este apêndice reúne os dados completos do experimento. A Tabela~\ref{tab:ap_icv} mostra o cálculo do ICV de cada módulo, e as Tabelas~\ref{tab:ap_lemmings1} a~\ref{tab:ap_wbuart32} trazem, para cada módulo e cada LLM, as coberturas (\%) e os mutantes mortos de cada estratégia nas duas rodadas. Abreviações: ZS = \textit{Zero-shot}; FS = \textit{Few-shot}; Esp = Especialista; Pln = \textit{Planning}; $k$/4 = mutantes mortos de 4; NP = não passou no circuito original; TO = excedeu o tempo limite. As coberturas dos \textit{testbenches} não aprovados estão registradas, mas não entram nas médias do trabalho, pois a simulação é interrompida no primeiro erro.
